# jakeweb

DAY 번호와 짧은 설명으로 웹사이트를 모아 보는 공개 목록입니다. GitHub Pages는 main 브랜치의 docs 폴더를 게시합니다.

## 새 사이트 등록

1. 사이트 오른쪽 위 **New Web**을 누릅니다.
2. RE2031 계정으로 로그인한 뒤 목록 파일을 편집합니다. 첫 등록은 빈 배열을 아래처럼 채웁니다. 다음 사이트부터는 배열 안에 항목을 쉼표로 구분해 추가합니다.
3. **Commit changes**를 누르면 GitHub Pages에 자동으로 반영됩니다.

```json
[
  {
    "day": 1,
    "url": "https://example.com",
    "description": "수능 AI안경을 거미줄로 가져오는 게임"
  }
]
```

실제 사이트 주소를 입력하세요. 방문자는 목록을 읽을 수 있고, 원본에 쓰기 권한이 있는 계정만 수정 사항을 바로 게시할 수 있습니다.
